# ブラウザで開く

- 種別: 機能設計書
- 対象 UC: UC-010 (docs/design/USECASES.md)

## 何を作るか

ブラウザで開くを実現する。UC-010のBR-043、BR-044に従う。

## 入出力と振る舞い

Issue・コメント一覧の`<C-o>`で選択中の行を開く。`<C-j>`・`<C-k>`はカーソル行の選択印をトグルし、それぞれ次行・前行へ移動する。選択がない場合はカーソル行1件を使う。対象は押下時に固定し、一覧順でブラウザへ渡す。Issue作成後の選択にも作成先URL1件を渡せる。失敗対象ごとに理由を表示する。

## API

GitHubから取得したHTTP(S) URLをブラウザ起動アダプタへ渡す。GitHub APIへの新たな要求は行わない。引数はシェルへ連結しない。共通実行境界はDESIGN.md「横断規約」参照。 Issue作成後は`require("github.features.links.open").open({url})`を呼ぶ。ブラウザの起動は共通process実行器を経由し、終了コードごとに結果を判定する。

## エッジケースの決定

空: 対象なしを案内し起動しない。境界: 単一または複数を一覧順に扱う。エラー: 失敗対象ごとに理由を表示する。並行: 対象を押下時に固定し後のカーソル変更を反映しない。再表示: URLは取得済みの一覧・作成結果を使う。
