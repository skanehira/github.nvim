# コメント一覧・プレビュー

- 種別: 機能設計書
- 対象 UC: UC-007 (docs/design/USECASES.md)

## 何を作るか

コメント一覧・プレビューを実現する。UC-007のBR-032、BR-033、BR-034、BR-035に従う。

## 入出力と振る舞い

一覧は`@投稿者`と本文先頭行を表示幅で整列する。削除済み投稿者は`[deleted]`と表示する。`K`はIssue一覧と共有するMarkdownプレビューを再利用し、一覧のフォーカスを維持する。プレビューの`q`で閉じる。

投稿者を `gh_issue_comment_user`、選択印を `gh_select` でハイライトする。再描画時は古い範囲を除去し、投稿者が削除済みの場合は投稿者の色を付けない。

`github://owner/repo/issues/<number>/comments`を開き、Issue一覧の`ghm`も同じ操作へ接続する。RESTで最大100件を取得し、投稿者と本文先頭行を表示する。削除済みの投稿者は判別できる代替名を表示する。`K`はカーソル行1件の取得済み全文を縦分割で表示する。`<C-j>`・`<C-k>`はカーソル行の選択印をトグルし、それぞれ次行・前行へ移動する。再取得時は選択印を解除する。0件・読込失敗・再読込・閉鎖後の応答はUC-007に従う。

## API

`GET repos/{owner}/{repo}/issues/{number}/comments?per_page=100`。応答配列の`id`、`user.login`、`body`、`html_url`を使い、返却順で最大100件を表示する。共通認証・エラーはDESIGN.md「横断規約」参照。

## 実装の配置

| 処理 | 層 | 実装先ファイル |
| --- | --- | --- |
| コメント一覧・プレビューの制御・表示 | 機能 | `lua/github/features/comments/list.lua` |
| 振る舞いの単体・結合検証 | テスト | `lua/github/features/comments/list_spec.lua` |

一覧の後続操作は `require("github.features.comments.list").state(buf)` から `target`、表示順の `items`、行番号をキーとする `selected` を参照できる。`refresh(buf)` は同じ一覧を再取得し、操作開始時に選択を解除する。

## エッジケースの決定

空: 0件表示、本文先頭行が空でも行を保持する。境界: 100件まで、画面ページ送りはしない。エラー: 初回は失敗を示し、再取得失敗は旧結果を保持する。並行: 要求世代とバッファ所有者で古い応答を破棄する。再表示: 明示的な再読込でそのIssueを再取得し、選択印を解除する。
