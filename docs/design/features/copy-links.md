# URLをコピーする

- 種別: 機能設計書
- 対象 UC: UC-011 (docs/design/USECASES.md)

## 何を作るか

URLをコピーするを実現する。UC-011のBR-045、BR-046に従う。

## 入出力と振る舞い

Issue・コメント一覧の`ghy`で選択中の行をコピーする。`<C-j>`・`<C-k>`はカーソル行の選択印をトグルし、それぞれ次行・前行へ移動する。選択がない場合はカーソル行1件。選択URLは一覧順に改行で結合し、末尾に余分な空行を付けず`+`レジスタへ書く。書込みを要求した件数を案内し、完了を確認できない場合は結果未確認と伝える。Issue作成後のURL1件も同じ処理で扱う。

操作対象のURLを固定した後に、元一覧の選択印を解除して再描画する。ブラウザ・providerの失敗時も、前回の選択は次の操作へ残さない。

## API

GitHub APIは呼ばず、クリップボードの書込みアダプタへ完全な文字列を渡す。provider不在など検知できる失敗は理由を案内する。Neovimの`setreg`はproviderの失敗を確実に返さないため、完了を確認できない場合は成功と断定せず結果未確認と案内する。作成後のURLは`require("github.features.links.copy").copy({url})`に渡す。共通外界境界はDESIGN.md「横断規約」参照。

## エッジケースの決定

空: 対象なしを案内し既存クリップボードを保持。境界: 複数URLは一覧順・改行区切り。エラー: provider不在を案内。並行: 対象を操作時に固定する。再表示: 取得済み一覧または作成結果のURLを使う。
