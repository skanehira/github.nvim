# URLをコピーする

- 種別: 機能設計書
- 対象 UC: UC-011 (docs/design/USECASES.md)

## 何を作るか

URLをコピーするを実現する。UC-011のBR-045、BR-046に従う。

## 入出力と振る舞い

Issue・コメント一覧の`ghy`で選択中の行をコピーする。`<C-j>`・`<C-k>`はカーソル行の選択印をトグルし、それぞれ次行・前行へ移動する。選択がない場合はカーソル行1件。選択URLは一覧順に改行で結合し、末尾に余分な空行を付けず`+`レジスタへ書く。成功時は件数を案内する。Issue作成後のURL1件も同じ処理で扱う。

## API

GitHub APIは呼ばず、クリップボードの書込みアダプタへ完全な文字列を渡す。providerの失敗を成功扱いしない。共通外界境界はDESIGN.md「横断規約」参照。

## 実装の配置

| 処理 | 層 | 実装先ファイル |
| --- | --- | --- |
| URLをコピーするの制御・表示 | 機能 | `lua/github/features/links/copy.lua` |
| 振る舞いの単体・結合検証 | テスト | `lua/github/features/links/copy_spec.lua` |

## エッジケースの決定

空: 対象なしを案内し既存クリップボードを保持。境界: 複数URLは一覧順・改行区切り。エラー: provider不在を案内。並行: 対象を操作時に固定する。再表示: 取得済み一覧または作成結果のURLを使う。
