# コメント投稿

- 種別: 機能設計書
- 対象 UC: UC-008 (docs/design/USECASES.md)

## 何を作るか

コメント投稿を実現する。UC-008のBR-036、BR-037、BR-038に従う。

## 入出力と振る舞い

一覧の`ghn`または`github://owner/repo/issues/<number>/comments/new`で対象Issue固定のMarkdown編集バッファを開く。`:write`時に送信本文とchangedtickを保持する。空白だけは送らない。処理中の追加保存は案内し再送しない。成功後は作成先を案内し、変更がなければバッファを閉じ、追記があれば未送信のまま保持する。元一覧があれば再取得し、再取得失敗と投稿結果を分ける。

## API

`POST repos/{owner}/{repo}/issues/{number}/comments`へJSON stdin `{"body":"..."}`を渡す。応答の`id`と`html_url`を成功結果として使う。結果未確認は自動再送しない。共通認証・エラーはDESIGN.md「横断規約」参照。

## エッジケースの決定

空: 空白以外1文字以上。境界: GitHubの検証に従い失敗内容を表示する。エラー: 入力を保持し結果不明を未投稿と断定しない。並行: 二重送信を抑え、送信後の追記を保持する。再表示: 投稿成功後に元一覧を再取得し、最大100件の範囲を表示する。
